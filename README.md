# 텔레스트레이션

그림과 추측이 한 칸씩 돌아가는 방. 4~10명, 방 번호 네 글자만 있으면 바로 시작한다.

보드게임 **Telestrations**(The Op)를 웹으로 옮긴 팬 프로젝트다.

## 어떻게 도는가

사람이 N 명이면 공책도 N 권, 라운드도 N 번이다.

| 라운드 | 하는 일 |
| --- | --- |
| 1 | 카드 여섯 개 중 하나를 골라 **자기 공책 첫 쪽**에 적는다 |
| 2 | 옆 사람 공책을 받아, 적힌 말을 보고 **그린다** |
| 3 | 또 옆으로 넘어온 공책의 그림을 보고 **무슨 말이었는지 적는다** |
| … | 그림과 말이 번갈아 쌓인다 |
| N | 공책이 주인 **바로 앞 사람**에게서 멈춘다 |

누구에게나 **바로 앞 쪽만** 보인다. 다 돌면 공책을 한 권씩 펴서 말이 어떻게 망가졌는지 같이 본다.

자리 `s` 인 사람이 `r` 라운드에 든 공책은 `(s - r + 1) mod N`. 1라운드에 자기 공책을
드는 것부터 이 식 하나로 떨어지고, 뒤집으면 공책 `b` 의 `i` 쪽을 채운 사람은 자리
`(b + i) mod N` 이다 — 별을 셀 때 이 식을 쓴다.

## 짜임새

```
public/index.html   화면 한 장. 그림판·연결·모든 단계가 여기 다 있다
src/index.js        들머리 — /new 로 빈 방 번호를 내주고, /room 을 방으로 넘긴다
src/room.js         방 하나 = Durable Object 하나. 판은 여기서만 안다
src/rules.js        규칙과 한도. Cloudflare 것이 하나도 안 들어와서 그냥 node 로 돌려 본다
src/words.js        제시어 272개 — 쉬움 112 · 보통 80 · 어려움 80
test.js             공책이 제대로 도는지, 카드가 말이 되는지
bots.js             혼자 확인할 때 옆자리를 채워 주는 봇
```

**그림은 PNG 가 아니라 획 좌표로 오간다.** 한 획이 `{색, 굵기, 점들}` 이고 좌표는
0~1023 정수다. 용량이 작고, 어떤 화면 크기에서도 또렷하게 다시 그려진다. 한 쪽에
담기는 양(획 400개·점 9000개)은 서버가 잘라 낸다.

**판은 메모리가 아니라 저장소가 원본이다.** 연결을 WebSocket Hibernation 으로 받아서
아무도 손대지 않는 동안 방이 잠들기 때문이다 — 깨어나면 저장소에서 다시 읽는다.
그림은 한 쪽에 하나씩 따로 둔다. 한 칸에 넣을 수 있는 크기(128KiB)가 정해져 있어서
판 전체를 한 덩어리로 두면 그림 몇 장에 금방 넘친다.

시간이 다 되면 안 낸 자리는 빈 쪽으로 메우고 넘어간다. 한 사람 때문에 판이 멈추지 않게.
세 시간 동안 아무도 안 오면 방은 스스로 지워진다.

## 돌려 보기

```bash
npm install
node test.js          # 규칙만 — 서버 없이 돈다
npx wrangler dev      # http://127.0.0.1:8787
```

### 혼자 시험하기

사람이 넷은 있어야 판이 도는데, 봇에게 옆자리를 맡기면 된다.

```bash
node bots.js ABCD       # 그 방에 봇 셋 — 나까지 넷이 된다
node bots.js ABCD 5     # 봇 다섯
```

브라우저에서 방을 먼저 만들고(번호가 제목 옆에 뜬다) 그 번호로 봇을 부르면, **방장은
사람**이라 시작과 공개 넘기기를 직접 몰 수 있다. 봇을 먼저 띄웠다면 봇이 방장이 되는데,
그때는 봇이 알아서 시작하고 공책도 넘겨 준다 — 판이 어떻게 도는지 구경만 할 때 편하다.

창을 나눠서 사람 여럿으로 해 보려면 **시크릿 창이나 다른 브라우저**를 써야 한다. 같은
브라우저의 일반 탭끼리는 `localStorage` 의 참가자 표식을 나눠 가져서 한 사람으로 잡힌다.

## 올리기

```bash
npx wrangler deploy
```

Cloudflare Workers 무료 플랜. 결제 수단을 등록하지 않았으니 한도를 넘어도 요금이 붙지
않고 그날 요청만 거절된다. 무료 플랜에서는 SQLite 저장소를 쓰는 Durable Object 만 쓸 수
있어서 `new_sqlite_classes` 로 잡아 두었다.
